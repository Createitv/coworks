## Does Coworks.dev require an account?

No. You can read the guides, watch embedded videos, and copy templates without signing into this site. Claude itself is a separate service operated by Anthropic.

## Where do I start a Cowork task?

Open Claude with an eligible account and follow the task entry in your current interface. Some users see separate Chat and Cowork choices, while other users see a unified interface. Use [the setup guide](/docs/setup) if your screen differs from a video.

## Do I need Claude Desktop?

Use Claude Desktop when your workflow needs local file access, computer use, or other capabilities that require a desktop connection. A task that uses only supported online sources may run in the web or mobile experience where enabled. Check the [official availability guide](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork) for the device and account you use.

## Is Claude Cowork included on the free plan?

Anthropic lists Cowork for eligible paid plans. Some free Claude features overlap with tasks shown in tutorials. Use the [plan guide](/docs/plans-and-pricing) and [official pricing](https://claude.com/pricing) to compare current availability and billing.

## Can Cowork read everything on my computer?

Give it access only to folders required for the task, and check the permission dialog. Try one test file before sharing a larger folder. Keep copies and require approval before moving, renaming, or deleting files. See [permissions and limitations](/docs/limitations).

## How do I know a connector is working?

Have Cowork find one known document or message and cite the original link. Open the link in the intended service account. If it fails, check the organization, connected identity, and sharing settings before reconnecting. Follow the [connector checklist](/docs/connector-checklist).

## How should I check a result?

Match the output against an answer key or review a few rows against the original records. For spreadsheets, also check totals, units, duplicate rows, and missing data. Use our [receipt audit exercise](/docs/receipt-audit) for a reproducible example.

## What if my first task fails?

Shrink the job to one sample and find the first point at which it fails: access, instructions, execution, or output. Try the [troubleshooting guide](/docs/troubleshooting) or consult [Claude Help](https://support.claude.com/) for account support.

## Why can’t I find Dispatch?

Anthropic limits Dispatch to some existing beta users. If it is missing, check [Dispatch availability and cloud alternatives](/docs/dispatch) rather than assuming the paid plan or mobile app will enable it.
