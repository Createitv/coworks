## Can I still set up Dispatch?

The [official Dispatch guide](https://support.claude.com/en/articles/13947068-assign-tasks-from-anywhere-in-claude-cowork), checked November 12, 2026, says the limited beta is closed to new users. Existing users who still see Dispatch can follow Anthropic’s pairing instructions. The [launch video](/videos/claude-cowork-dispatch-from-phone) shows the original experience.

## Choose the right route

| Situation | Route | Check before starting |
| --- | --- | --- |
| You already have Dispatch and need a file on your computer | Dispatch | Keep the computer awake and Claude Desktop open. Make sure the working folder is connected. |
| Dispatch is missing and the task only needs online sources | Cloud Cowork | Check account and workspace availability, then test one approved connector. |
| The task needs local files but you cannot use Dispatch | Cowork with Claude Desktop | Check that the desktop connection and local folder access are available in your setup. |

See [Cowork on web, desktop, and mobile](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile) for current platform behavior.

## Run one handoff you can verify

Use a sample note with a known heading. Request a five-line summary and name the source file in your brief. Check that you can open the result on the device where you plan to review it. If the task fails, check the account and the desktop connection before granting any additional access. For cloud tasks, follow the [connector checklist](/docs/connector-checklist).
