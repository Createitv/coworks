## Six habits that make tasks easier to check

| Habit | Example | Result to check |
| --- | --- | --- |
| Write a deliverable first | Save a Markdown brief with decisions and sources | Can you open and verify the file? |
| Start with a narrow sample | Use three receipts across two currencies | Do totals and currencies match the originals? |
| Separate planning from changes | Ask for an old-to-new file path table | Are moves reversible and names unique? |
| Keep a reusable instruction | Put approval rules into folder instructions | Does it stop before overwriting a source? |
| Cite facts close to the claim | Add source links to each decision | Can a reader retrace them? |
| Batch similar work | Process ten files that share a format | Are malformed or unknown files flagged? |

## A prompt you can adapt

> Read the approved files in [folder]. Produce [deliverable] in [format]. Include [required fields] and a source for each decision. Leave uncertain values blank and explain them in a review section. Do not modify the source files. Stop and ask if you need more access.

Try the [prompt library](/docs/templates) for examples with checks specific to documents, data, and recurring work.

## Measure a real time saving

Run the same representative sample manually and in Cowork. Separate active preparation, waiting, supervision, and review. Count incorrect fields, omissions, and fixes before comparing time. Faster output is useful only if it still meets your quality bar. The [receipt audit](/docs/receipt-audit) supplies the same inputs and an answer key for both runs.

## Choose a safe first automation

Save a prompt only after you can reproduce a good result. Give recurring jobs a timezone, source window, and failure behavior. Run the first scheduled job in draft mode and review the output against the [scheduled task checklist](/docs/scheduled-tasks).
