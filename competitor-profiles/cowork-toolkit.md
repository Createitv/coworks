# Cowork Toolkit

观察日期为 2026-11-12。公开网站主体是单页资源库，用户从课程 PDF 入口或站内搜索进入按阶段组织的资源卡片。卡片提供复制和展开文本操作。 [Cowork Toolkit](https://coworktoolkit.com/)

| 界面 | 内容 |
| --- | --- |
| 页面首屏 | 下载课程指南、按名称或步骤编号搜索、三个阶段的快捷跳转 |
| Set Up | 工作区说明、记忆、写作风格、个人背景和访谈提示词 |
| Build | 按工作站、项目和技能组织提示词，包括邮箱与日历场景 |
| Automate | 将已有工作流程接到定期运行和复查 |

公开正文通过网页抓取审阅。外链 PDF 的内容和下载权限未验证。流量、关键词总量和反链数据未取得。
