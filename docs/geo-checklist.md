# GEO checks for Coworks.dev

The canonical HTML is the version to cite. Markdown versions of guides and video notes are generated from the same content and carry a canonical Link header and a noindex header. They are fetchable but excluded from the XML sitemap. The public JSON catalog links to those copies and to the Quick answer section of each guide.

Priority product guides show a source-review date and links to the vendor references used for the answer. Review those links when availability, pricing, or permissions change. Do not advance a date unless the source was actually checked, or present exercises as observed customer results.

Use this repeatable query set to monitor results by engine, date, country and language. Record the exact URL cited and whether the answer reflects current sources. A missing citation is a result to record, not a reason to fabricate coverage.
