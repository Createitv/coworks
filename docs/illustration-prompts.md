# Coworks documentation illustrations

The 18 original illustrations were made with the built-in OpenAI image generator. Website assets are in `public/docs/illustrations` in 1200×800 and 480×320 WebP. The source renders are separate from the web assets.

## Prompt template

> Use case: illustration-story. Wide 3:2 editorial illustration for the Coworks.dev documentation article about {article slug with spaces}. Depict {scene}. Make that exact workflow visually legible at phone width. Warm off-white paper ground, burnt-orange accent, muted blue-gray details, dark ink, fine paper grain, clean flat editorial shapes, generous margins, cohesive technical handbook style. This is a concept illustration, not a product UI. No typography, numbers, screenshots, logos, watermarks, or text.
