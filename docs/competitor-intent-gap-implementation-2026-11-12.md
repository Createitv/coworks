# Coworks 与 claudecowork.im 搜索意图逐项补充记录

核对日期为 2026 年 11 月 12 日。竞品 sitemap 有 4,014 个 URL，Coworks 改动前有 56 个。数量差距主要来自竞品 3,846 个平铺资源详情页。抽查发现部分竞品资源详情的 canonical 指向首页，因此 URL 数量不能直接视为有效索引量或独立搜索需求。

## 每个新页面的最低内容标准

每页必须有唯一标题、唯一主关键词、直接答案、任务边界、输入、可复制提示词或明确步骤、预期输出、验收方法、失败处理和相关内链。连接器页面还必须引用官方当前资料，区分读取与写入，并避免承诺固定的界面或权限行为。

## 暂不照搬的页面

- 未验证 Cowork 兼容性的 Claude Code 技能详情
- 只有名称不同、正文可互换的资源页
- 没有真实输入、产出和验收方法的场景变体
- canonical 不指向自身的批量详情页模式
- 没有 Search Console 查询、站内需求或官方能力依据的长尾页面

后续扩展先看 Search Console 的查询、落地页、国家、设备和近 28 天趋势。达到独立意图标准后，再从 Slack、日历规划、销售研究、文件批处理等候选中逐页增加。
