# Coworks.dev 页面与搜索意图

对标来源为 [五站关键词报表](competitor-search-benchmark-2026-11-12.md) 和 [claudecowork.im 站点地图](https://claudecowork.im/sitemap.xml)。产品概览、套餐和教程的关键词数据见报表。其他查询方向是内容假设，后续以 Search Console 验证。

每页集中解决一个主要任务，可以自然回答同一意图的多个问法。竞品的套餐页同时承接 pricing、plans 和 free，概览页同时承接产品名和 what is。英文标题、摘要、导航文案和正文都应该反映用户看到的实际答案。
